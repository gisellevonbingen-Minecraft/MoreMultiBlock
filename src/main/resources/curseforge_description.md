# [Mekanism: More MultiBlock](https://www.curseforge.com/minecraft/mc-mods/mekanism-more-multiblock) Ver 1.0 リリース :bangbang:

## Mekanismに新しいマルチブロックを追加します。
## **Radioactive Waste Vault**
*  放射性廃棄物バレルのマルチブロック版です。
   サイズが大きければ大きい程、容量と核廃棄物の処理スピードが増加します。

### サイズ
* **最大 3 × 3 × 3**
* **最大 18 × 18 × 18**

### 構成ブロック
* **Radioactive Waste Vault**
* **Radioactive Waste Valve**
